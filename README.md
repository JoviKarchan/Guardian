ai + blockchain for a distraction-free, accountable internet

the internet is built to keep people distracted. gambling sites, endless social media feeds, and harmful content make it harder to stay focused and build healthy habits online.

most blockers are easy to bypass, centralized, generic, and don’t actually understand the person using them.

guardian combines ai personalization with the security and transparency of the ethereum virtual machine (evm). it learns user behavior and adapts restrictions based on personal struggles while using cryptographic message signing so only authorized users or guardians can make changes. everything is backed by blockchain transparency and accountability.

guardian is focused on helping people regain focus, build discipline, and create a healthier online environment instead of just acting like another site blocker.

tech stack: react + vite, solidity smart contracts, evm, metamask/walletconnect authentication, guardian ai personalization
